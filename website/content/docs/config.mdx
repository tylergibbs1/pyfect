A `Config[A]` says which keys to read and how to decode them. Configs are effects that fail with
`ConfigError`, so they compose with everything else.

<include meta='title="read.py"'>../../snippets/config/read.py</include>

Missing data is **absent**: `with_default` and `option` (`cfg.option()` or `config.option(cfg)`)
recover it. Data that is present
but invalid **fails**, so a typo in `PORT` is an error, not a silent default.

## Sources and secrets

A `ConfigProvider` is where values come from: `from_env` (the default), `from_dot_env`,
`from_dir`, `from_unknown` (nested dicts) or your own lookup. `from_dot_env` and `from_dir`
read through the `FileSystem` service (and `Path`), so provide `platform.layer` or a test
file system. Install one with `config_provider.layer`. `nested` reads a config under a prefix, and `config.redacted` keeps a
secret out of logs and error messages.

<include meta='title="sources.py"'>../../snippets/config/sources.py</include>

Constructors: `string`, `integer`, `number`, `boolean`, `port`, `url`, `duration`, `literal`,
`log_level`, `byte_size`, `date_time`, `redacted`, `list_of`, `dict_of`; combine with
`config.all`, `all_dict` or `@config.gen`.
`url` gives a `Url` (`fx.Url`, JavaScript's `URL`), parsed as `new URL(text)` parses it;
see [URLs](/docs/platform#urls).
`date_time` reads text as JavaScript's `Date` does, V8's forms included (`2024-01-15`,
`2024-01-15T10:00`, `Jan 15 2024 10:00 PM EST`, `1/15/2024`), and gives a UTC `datetime`.
A date alone is UTC; a time that names no zone is local time, as in Effect.
