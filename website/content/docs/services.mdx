<Split>
<SplitProse>

A service is a dependency an effect asks for by **tag**: a database, a mailer, a clock. The
effect's third type parameter lists the tags it needs, and it can't run until a **layer**
provides them.

A tag's identity is separate from its shape, so two tags (`Primary`, `Replica`) can share one
interface. `fx.Reference` is a tag with a default value, which needs no layer.

## Layers

<Split>
<SplitProse>

A `Layer[ROut, E, RIn]` builds the services `ROut`, may fail with `E`, and needs `RIn` to do it.

- Constructors: `layer.succeed(Tag, service)`, `layer.sync(Tag, f)`, `layer.effect(Tag, eff)`
  (which can use other services, and `acquire_release` for resources).
- `fx.provide(layer)` on an effect, and `layer.provide(other)` on a layer, remove exactly what
  the layer builds and leave the rest of the requirements.
- `layer.merge(a, b)` builds several layers concurrently.
- Layers are memoized by identity: keep them in module-level constants, and each is built once
  per program however many effects use it.

For tests, `layer.mock(Tag, member=...)` stubs a service, and `testing.layer_fixture` builds a
layer once per pytest scope (see [Testing](/docs/testing)).
