A service is a dependency an effect asks for by **tag**: a database, a mailer, a clock. The
effect's third type parameter lists the tags it needs, and it can't run until a **layer**
provides them.

A tag's identity is separate from its shape, so two tags (`Primary`, `Replica`) can share one
interface. `fx.Reference` is a tag with a default value, which needs no layer. A tag can't be
subclassed (a subclass would type-check as provided by its parent): declare each tag from
`fx.Tag` or `fx.Reference`.

## Layers

A `Layer[ROut, E, RIn]` builds the services `ROut`, may fail with `E`, and needs `RIn` to do it.

- Constructors: `layer.succeed(Tag, service)`, `layer.sync(Tag, f)`, `layer.effect(Tag, eff)`
  (which can use other services, and `acquire_release` for resources).
- `fx.provide(layer)` on an effect, and `layer.provide(other)` on a layer, remove exactly what
  the layer builds and leave the rest of the requirements.
- `layer.merge(a, b)` builds several layers concurrently.
- An HTTP route that reads a service gets it per request, not from `layer.provide` on the routes
  layer: use `router.provide_request(layer)` (see
  [Routes that need services](/docs/http-server#routes-that-need-services)).
- Layers are memoized by identity within one `fx.provide`: keep them in module-level constants,
  and each is built once however many layers in that provide need it. Two separate
  `fx.provide(layer)` calls build it twice, as in Effect; provide it once around the whole
  program (or use `ManagedRuntime`) to share it. A layer that must differ per key of a
  `LayerMapService` is the exception: make it in the lookup (see
  [Sharing by key](/docs/resources#sharing-by-key)).

For tests, `layer.mock(Tag, member=...)` stubs a service (see
[Mocking a service](#mocking-a-service)), and `testing.layer_fixture` builds a layer once per
pytest scope (see [Testing](/docs/testing)).

## Mocking a service

`layer.mock(Tag, member=...)` provides a service made of the members you give it, so a test
stubs only what it uses. Any other member is an effect, and a method returning one, that dies
with `UnimplementedError`. pyright doesn't check the member names: a misspelt one leaves the
real member unmocked, and the defect names the close match.

The snippet declares its tag with `key="Mail"`. A tag's key is its identity, as in Effect: two
tag classes with the same key are one service, whichever of them provides it or reads it. The
key is also the name pyfect shows: in `Service not found: Mail`, in a context's repr, and in the
defects `layer.mock` raises below. Without `key=` it is the class's module and name, such as
`app.mail.Mail`, so tags declared in different places stay apart. A short key like `"Mail"` is
shared by any library that picks it too: declaring a second tag class with a key another
declaration holds warns with `DuplicateTagKeyWarning`, and giving one of them a different key
keeps them apart.
