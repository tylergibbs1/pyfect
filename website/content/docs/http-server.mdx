A handler is an effect that gives an `HttpServerResponse`. Routes are added to the
`HttpRouter` by layers, so a route's handler can ask for any service and the layer's type
says which ones the server must provide. `router.serve(routes)` serves them on the
`HttpServer` in the context, and needs whatever else the routes' layer needs (services, and
markers such as an [RPC group](/docs/rpc)'s `HandlersFor[Group]`), so they can be provided to
the server layer; `uvicorn_server.layer(port=...)` is one on uvicorn (install the
`pyfect-dev[server]` extra), and `live_server.layer` one on the standard library.

## Routes

`router.use(f)` is a layer that calls `f` with the router; `routes.add(method, path, handler)`
adds a route. A path matches `:name` segments and `*` wildcards; `router.params` gives the
matched values, and `router.schema_path_params`, `schema_params` and `schema_json` decode the
path, the query and the JSON body with a [schema](/docs/schema). `schema_json`'s schema is a
struct of the request: `body`, `method`, `url`, `headers`, `cookies`, and `pathParams` and
`searchParams`, spelled in camelCase as in Effect (a `params` key fails every request with a
400). A request that matches no route gets a 404, and a handler that fails gets a 500 unless
it handles the error itself.
As in Effect, two failures answer otherwise: a `SchemaError` (a request that doesn't decode)
gets an empty 400 and a `NoSuchElementException` an empty 404.

## HTML templates

`server_response.html_template(strings, *values)` renders a template as a `text/html`
response, and `html_stream` streams one; `template.make` gives the text. A value can be an
effect or, for `html_stream`, a stream. As in Effect, values are inserted without HTML
escaping, so text from a user or a log line must go through `html.escape` first.

## Middleware

A middleware is a function of the handler it wraps. `router.middleware(f)` makes route
middleware, provided to the route layers it should wrap with `layer.provide(m.layer)`, and
`router.middleware(f, global_=True)` a layer that wraps every request. `router.cors(...)`
answers preflight requests and adds the CORS headers. Each request is logged unless
`disable_logger=True`. `routes.pipe(router.provide_request(services))` builds `services` once
and gives them to every request of those routes, removing their `Requires[...]`, as Effect's
`HttpRouter.provideRequest` (see [Adopting in an asyncio app](/docs/asyncio-apps#routes-mounted-in-the-app)).

<Callout title="serve(middleware=...) can't change the response">

`serve(..., middleware=...)` wraps the whole request, sending included, so the response it
returns is dropped, as in Effect: `lambda app: app.map(lambda res: res.set_header(...))` there
adds nothing. It is for the app-wide middleware of `pyfect.http.middleware`, such as
`compression()`, which change the response through `http_effect.append_pre_response_handler`.
To change every response, use `router.middleware(f, global_=True)`. A 404 or a failed handler
is still a failure inside it, so `f` sees it only by catching it (`catch_cause`, then
`server_error.cause_response`).

</Callout>

## Serving with uvicorn

`router.serve(routes)` is a layer, so a program serves until it is interrupted by
launching it: `fx.run_main(Main.launch())`. On Ctrl-C the server stops accepting connections
and gives the requests in flight `graceful_shutdown_timeout` (20 seconds) before
interrupting them. A streamed body still open then, such as an SSE stream, stops where it
is, so one open server-sent events response holds shutdown for the full 20 seconds; pass
`uvicorn_server.layer(port=8000, graceful_shutdown_timeout="3 seconds")` to wait 3 seconds instead.
`disable_preemptive_shutdown=True` interrupts the requests in flight at once.
`router.to_asgi(routes)` is the same app as an ASGI application, for `uvicorn main:app` or
any other ASGI server; its layers are built at the server's startup and released at its
shutdown, and its requests run with their services, so whatever the routes need its layer must
build. `hypercorn_server.layer(port=...)` serves on hypercorn instead, with HTTP/2 (the
`pyfect-dev[http2]` extra).

`asgi.from_asgi(app)` goes the other way: it mounts an ASGI application, such as a FastAPI or
Starlette one, as a route, for HTTP requests only (WebSocket upgrades reach it as `http`
requests, as with Effect's `fromWebHandler`). Mounted under a path, its route needs
`router.prefix_route(...)`, which makes the path the app's `root_path`.
[Adopting in an asyncio app](/docs/asyncio-apps#serving-with-hypercorn) moves such an app to
pyfect step by step, and [serves over TLS](/docs/asyncio-apps#serving-over-tls).

## WebSockets

A handler serves a WebSocket by upgrading its request: `request.upgrade` gives a socket
(`request.upgrade_with(headers=...)` adds response headers to the `101`, for protocols other
than `websocket`). The socket opens only when its `reader` is taken, in a scope that closes
it: the `101` is sent then, and until then every `writer.write` waits. So a handler that only
sends must still take the reader, or it hangs on its first write. The client's socket from
`pyfect.socket.make_web_socket(url)` works the same way. All of this is as in Effect.

Two more rules, also Effect's:

- Once the reader's scope closes, the socket is gone and a write waits forever: it does not
  fail. Keep the reader's scope open for as long as the handler writes, as `shout` does.
- `reader.pull` and `so.to_stream` fail with a `SocketError` when the socket closes, even with
  code 1000 (a normal close). `catch_if(so.is_clean_close, ...)` ends the stream instead.

## Security defaults

The server refuses unsafe input without any setting, and each limit can be changed where an
app needs more room.

- A whole-body read (`request.text`, `json`, `schema_json`, HttpApi payloads, multipart) stops
  at `MaxBodySize`, 10 MiB by default, with a 413. Provide a larger `ByteSize`, or `None`, on
  the routes that need it. A streamed body (`request.stream`) is read as far as the handler
  reads it.
- `live_server.layer` closes a connection whose request has not fully arrived after
  `request_timeout` (300 seconds). It answers 400 to a `Host` that is not a host and port, to
  a request target that is not a path, `*` or an absolute `http(s)` URL, to framing headers
  padded with anything but spaces and tabs, and to malformed trailers or chunk extensions.
- Behind ASGI, a request URL is built only from a valid `Host` (else the server's address),
  and a path that does not start with `/` is a 400. An app mounted with `asgi.from_asgi` or
  `from_web_handler` keeps `%2F` encoded and never gets a `.` or `..` segment.
- WebSocket upgrades from a browser page of another origin get a 403; list more origins with
  `layer.succeed(AllowedOrigins, origin.allow(...))` from `pyfect.http.origin`. A WebSocket
  write waits while more than 64 KiB are unsent. `live_server.layer` accepts
  `permessage-deflate` only with `websocket_per_message_deflate=True` (or a
  `live_server.PerMessageDeflate(...)`), and a message's inflated size counts against
  `websocket_max_message_size`.
- The decompression middleware counts every decoded byte against the body limit and accepts
  at most two stacked codings. `router.cors(credentials=True)` needs a list of origins
  without `*`. A multipart boundary must follow RFC 2046 (1 to 70 characters). A response
  header with a control character is never sent.
- In [HttpApi](/docs/http-api), a body without a `Content-Type` gets a 415 instead of being
  read as JSON, and `security_set_cookie` sets `Secure`, `HttpOnly` and `SameSite=Lax`.

skip the socket, `router.in_memory_client(routes)` answers requests in memory and streams
response bodies as they are written (see [Testing](/docs/testing)).
