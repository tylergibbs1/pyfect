A handler is an effect that gives an `HttpServerResponse`. Routes are added to the
`HttpRouter` by layers, so a route's handler can ask for any service and the layer's type
says which ones the server must provide. `router.serve(routes)` serves them on the
`HttpServer` in the context, and needs whatever else the routes' layer needs (services, and
markers such as an [RPC group](/docs/rpc)'s `HandlersFor[Group]`), so they can be provided to
the server layer; `uvicorn_server.layer(port=...)` is one on uvicorn (install the
`pyfect-dev[server]` extra), and `live_server.layer` one on the standard library.

## Routes

`router.use(f)` is a layer that calls `f` with the router; `routes.add(method, path, handler)`
adds a route. A path matches `:name` segments and `*` wildcards; `router.params` gives the
matched values, and `router.schema_path_params`, `schema_params` and `schema_json` decode the
path, the query and the JSON body with a [schema](/docs/schema). A request that matches no
route gets a 404, and a handler that fails gets a 500 unless it handles the error itself.

## Middleware

A middleware is a function of the handler it wraps. `router.middleware(f)` makes route
middleware, provided to the route layers it should wrap with `layer.provide(m.layer)`, and
`router.middleware(f, global_=True)` a layer that wraps every request. `router.cors(...)`
answers preflight requests and adds the CORS headers; `serve(..., middleware=...)` takes the
app-wide middleware of `pyfect.http.middleware`, such as `compression()`. Each request is
logged unless `disable_logger=True`.

## Serving with uvicorn

`router.serve(routes)` is a layer, so a program serves until it is interrupted by
launching it: `fx.run_main(Main.launch())`. On Ctrl-C the server stops accepting connections
and gives the requests in flight `graceful_shutdown_timeout` (20 seconds) before
interrupting them. A streamed body still open then, such as an SSE stream, stops where it
is, so one open server-sent events response holds shutdown for the full 20 seconds; pass
`uvicorn_server.layer(port=8000, graceful_shutdown_timeout="3 seconds")` to wait 3 seconds instead.
`disable_preemptive_shutdown=True` interrupts the requests in flight at once.
`router.to_asgi(routes)` is the same app as an ASGI application, for `uvicorn main:app` or
any other ASGI server; its layers are built at the server's startup and released at its
shutdown.

## Security defaults

The server refuses unsafe input without any setting, and each limit can be changed where an
app needs more room.

- A whole-body read (`request.text`, `json`, `schema_json`, HttpApi payloads, multipart) stops
  at `MaxBodySize`, 10 MiB by default, with a 413. Provide a larger `ByteSize`, or `None`, on
  the routes that need it. A streamed body (`request.stream`) is read as far as the handler
  reads it.
- `live_server.layer` closes a connection whose request has not fully arrived after
  `request_timeout` (300 seconds). It answers 400 to a `Host` that is not a host and port, to
  a request target that is not a path, `*` or an absolute `http(s)` URL, to framing headers
  padded with anything but spaces and tabs, and to malformed trailers or chunk extensions.
- Behind ASGI, a request URL is built only from a valid `Host` (else the server's address),
  and a path that does not start with `/` is a 400. An app mounted with `asgi.from_asgi` or
  `from_web_handler` keeps `%2F` encoded and never gets a `.` or `..` segment.
- WebSocket upgrades from a browser page of another origin get a 403; list more origins with
  `layer.succeed(AllowedOrigins, origin.allow(...))` from `pyfect.http.origin`. A WebSocket
  write waits while more than 64 KiB are unsent.
- The decompression middleware counts every decoded byte against the body limit and accepts
  at most two stacked codings. `router.cors(credentials=True)` needs a list of origins
  without `*`. A multipart boundary must follow RFC 2046 (1 to 70 characters). A response
  header with a control character is never sent.
- In [HttpApi](/docs/http-api), a body without a `Content-Type` gets a 415 instead of being
  read as JSON, and `security_set_cookie` sets `Secure`, `HttpOnly` and `SameSite=Lax`.

## Testing routes

A test serves the routes on `layer_test` and sends requests with the `HttpClient` it gives. To
skip the socket, `router.in_memory_client(routes)` answers requests in memory and streams
response bodies as they are written (see [Testing](/docs/testing)).
