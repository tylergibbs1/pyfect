pyfect needs Python 3.13 or newer; its one dependency is `typing-extensions`. Install it from
PyPI: the distribution is named `pyfect-dev` and you import `pyfect`.
The PyPI package called `pyfect` is an unrelated project.

<InstallCommand
  uv="uv add pyfect-dev"
  pip="pip install pyfect-dev"
/>

Extras add integrations: `otel` (OpenTelemetry, `pyfect.otel`), `hypothesis`, `pydantic` and
`msgspec` ([Pydantic and msgspec](/docs/pydantic-msgspec)), `httpx` (the HTTP client backend), `websockets`, `server` (the uvicorn HTTP server),
`http2` (the HTTP/2 server on hypercorn), `pg` (PostgreSQL on psycopg), `mysql`, `mssql`, `redis`, `eventlog` (event log encryption), `brotli` (`br`
response compression), `intl` (`Intl`-style date formatting on babel) and `regex` (more ECMAScript patterns in schemas). For example:

<InstallCommand
  uv='uv add "pyfect-dev[otel]"'
  pip='pip install "pyfect-dev[otel]"'
/>

Importing a module whose extra is missing raises an `ImportError` with the command that installs it.

## Type checking

pyright is the type checker pyfect is built for; its inference is what makes errors and services
part of the type. Use strict mode, with one setting turned off: pyright infers an unannotated
generator's send type as `Unknown` ([pyright#10279](https://github.com/microsoft/pyright/issues/10279)),
and effect generators never use it.

```toml title="pyproject.toml"
[tool.pyright]
typeCheckingMode = "strict"
reportUnknownParameterType = false
```
