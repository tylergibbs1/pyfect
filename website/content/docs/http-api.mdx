An `HttpApi` is a declaration: groups of endpoints, each with its method, path and the
schemas of its params, query, payload, headers, success and errors. The server's handlers,
the client's methods and the OpenAPI document all come from it, so they can't disagree, and
pyright checks a handler's return value and a client call's arguments against the same
schemas.

## Declare and implement an API

`endpoint.get`, `post`, `put`, `patch`, `delete`, ... declare endpoints; a class extending
`HttpApiGroup` holds them, and `HttpApi.make(name).add(Group)` collects the groups. An error
schema's `http_api_status` annotation is the status it is sent with.

A group's own members can't be endpoint attributes: `add`, `annotate`, `annotate_endpoints`,
`annotate_endpoints_merge`, `annotate_merge`, `annotations`, `endpoints`, `identifier`, `key`,
`make`, `method`, `middleware`, `origin`, `prefix` and `top_level`. Naming one fails with a
`TypeError` as the class is created. Name the attribute `add_item` and the endpoint itself
what you like: `add_item = endpoint.post("add", "/items")`.

A handler takes an `HttpApiRequest` with the decoded `params`, `query`, `payload` and
`headers`, and gives the success value or fails with a declared error.
`builder.group(api, Group, ...)` is the layer of a group's handlers; building it dies if an
endpoint has no handler. `builder.layer(api)` adds every group's routes to the
[router](/docs/http-server) and needs each group's layer, which pyright checks, so
`router.serve` serves the API like any other routes.

`client.make(api)` derives a client: `get_group(api_client, Users).get_user(params={"id": 1})`
encodes the request, sends it with the `HttpClient` and decodes the response, failing with
the endpoint's declared errors as values of their own classes. `get_group` is typed as the
group you name, and a group the API lacks is a pyright error. A method's `response_only`
gives the raw response; `client.decode_response(api, Users, Users.get_user)` decodes it
later, as the method would have. Two endpoints with the same method and path are an error
when the routes are built.

A request whose params or payload don't match the schemas gets an empty 400 before any
handler runs, and the server logs the `HttpApiSchemaError` with the schema issue. To tell
the client what was wrong, build the routes with
`builder.layer(api, schema_error_details=True)`: the 400 then carries
`{"_tag": "HttpApiSchemaError", "kind": "Payload", "message": "Missing key\n  at [\"url\"]"}`.
It is off by default, as in Effect, since the message describes your schemas.

## Problem details

`error.Problem` declares an [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457) error:
`class OutOfCredit(Problem, type=..., status=..., title=...)` with its own fields as
extensions. An endpoint failing with it answers with that status and an
`application/problem+json` body, the OpenAPI document lists it so, and the client decodes it
back by its `type` into an `OutOfCredit`. `detail` and `instance` are optional on every
problem. `schema.as_problem(title=...)` sends an error class you already have as a problem.

Add the `middleware.ProblemDetails` middleware to the API and provide
`layer_problem_details()` to answer requests that don't decode with a `BadRequestProblem`
instead of the empty 400; `include_details=True` adds `errors`, each a path starting with
the slot (`query`, `payload`, ...) and a message. A response that fails to encode becomes an
`InternalServerErrorProblem`, and the schema error is reported once. `http.problem_details`
has the plain RFC 9457 schema for problems from other servers.

## Security

A middleware runs around the handlers of the endpoints it is added to. Declare one as a
class over what it gives the handlers and how it fails:
`HttpApiMiddleware[Caller, Unauthorized]` provides a `Caller` and may fail with
`Unauthorized`, whose schema is the class's `error`. For several errors give a tuple,
`error = (Unauthorized, Forbidden)`, as for an endpoint's `error`: each member answers with
its own `http_api_status`. `S.Union(Unauthorized, Forbidden)` is one schema with no status of
its own, so either error answers 500 (with its body), unless the union itself is annotated, as
in Effect. With
`security={"bearer": security.bearer}` it reads a bearer token; `security.basic` and
`security.api_key(key=..., in_="header")` read the other kinds. A group declared
`HttpApiGroup[Authorization]` puts every one of its endpoints behind it, and
`endpoint.middleware(Authorization)` puts one endpoint behind it.

The implementation is a layer: `layer.succeed(Authorization, {"bearer": bearer})` maps each
security name to a function of the handler's effect and a `SecurityOptions`.
`options.credential` is the decoded credential, a `Redacted` string for a token (empty when
the request has none), and the function either fails or runs the handler with what it
provides. Pyright checks that the handler's `Caller` is provided.

On the client side, `middleware.layer_client(Authorization, send)` runs `send` around every
request to the middleware's endpoints: it gets a `ClientMiddlewareOptions` and sends the
request on with `options.next(...)`, here with the token added. Provide it to `client.make`.

## Uploads and streams

`schema.as_multipart(S.Struct(Upload, file=multipart.SingleFileSchema), max_file_size=...)`
declares a `multipart/form-data` payload. The server writes each file part to a temporary
file before the handler runs, and the handler gets a `multipart.PersistedFile` with its
`name`, `content_type` and `path`; the file is removed when the request ends.
`SingleFileSchema` takes exactly one file for the field. A client sends the payload as an
`http.body.FormData`, built with `append(name, value)`, where a value is a string or a
`body.File(content, name, content_type)`. For uploads too large to keep,
`as_multipart_stream` gives the handler a stream of parts instead. Unlike Effect, both are
bounded by default: 1,000 parts, and 100 files and 100 MiB written to disk; `max_parts`,
`max_persisted_files` and `max_persisted_size` raise a limit, or remove it with `None` (see
[security defaults](/docs/http-server#security-defaults)).

`schema.StreamSse(data=...)` declares a `text/event-stream` response: the handler gives a
`Stream` and each element is sent as one event, encoded by the schema. The client method
gives back a `Stream` of the decoded events, so `run_for_each` follows them as they arrive.
`StreamSse(events=...)` sends whole events (with `event` and `id`) instead of their data,
and `error=` encodes a failure of the stream as an event the client fails with. Event data
goes through its schema's JSON codec, so dates and big integers are strings on the wire.

`StreamUint8Array` and `StreamNdjson` also take a list of content types,
`content_type=["application/jsonl", "application/json"]`: a payload is accepted under any of
them, a response is sent with the first unless a declared `content-type` header picks
another, and the client decodes the stream whatever type arrives.

## OpenAPI documentation

`openapi.from_api(api)` is the API's OpenAPI 3.1 document, with a JSON Schema for each
schema. Annotations add to it: `openapi.Title`, `Version` and `Description` on the API,
`Summary`, `Description` and `Deprecated` on an endpoint. `builder.layer(api,
openapi_path="/openapi.json")` serves the document, and `swagger.layer(api)` and
`scalar.layer(api)` serve documentation pages for it, bundled so they need no network.

## Testing handlers

`test.groups(api, (Users,), layer=TestUsers)` gives a client whose requests the handlers
answer in memory: no server or port, but the same encoding, decoding and statuses as over the
network. A request the server itself would refuse, such as a body past `MaxBodySize`, is a
defect of the call holding the server's `HttpServerError` rather than its status, as in
Effect's `HttpApiTest`. The handlers' own services come from the layer the test passes, which stays open
until the test's scope closes, so a scoped resource in it (a database pool, a `FiberMap`)
is still there when a handler runs. Pyright checks that the layer provides every served
group.

Pass the layer to `groups` rather than piping `fx.provide(TestUsers)` onto it: that releases
the layer as soon as the client is made, and the handlers then run against closed services.
A `FiberMap` or `Scope` used after it closes interrupts the caller and says which one was
closed.
