# The count is the live-clock sleeps a run completed (tests/_count_sleeps.py): each finished
# LiveClock.sleep adds its duration, an interrupted one adds nothing, and sleeps that run at
# the same time add up. In these entries background poll loops dominate the total, so it grows
# with how long the run takes. The limit is about twice the worst total measured; a snippet
# whose total falls under 2.5 s is fixed, and its line goes. Waits outside the clock (network,
# blocking calls, a database's own timers) are not counted: the 60 s hang alarm covers them.
# A line is `snippet limit  # reason` (tests/_inventory.py).
